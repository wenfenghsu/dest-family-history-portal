# DEST 家族史收案工作台

合作醫院的一等親大腸癌家族史高風險收案入口。保留原始 Flask／Gunicorn 架構，同時支援純靜態網站部署。

## 本版功能

- 手機、平板與桌面適用的繁體中文介面。
- 收案前準備檢核與即時進度；只存在當次頁面，不儲存個案資料。
- 既有抽籤系統入口與可設定的家族圖譜入口。
- 流程導覽、可展開的使用說明、鍵盤操作及列印樣式。

此專案仍是入口網站，不含個案資料庫、登入、實際抽籤或家族圖譜編輯器。各系統的資格判定、權限、資料儲存及結果以其實際功能及核准研究計畫為準。

## 設定入口

編輯 `static/config.js` 的 `lotteryUrl` 與 `pedigreeUrl`。只接受 HTTPS 網址。家族圖譜尚無正式網址時保持空字串，畫面會顯示尚未設定，不導向原始範例網址。

## 執行

```sh
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

本機已以 Python 3.12 驗證。原專案固定的 Flask / Werkzeug 版本不支援 Python 3.14。

開啟 http://127.0.0.1:8887 或 http://127.0.0.1:8887/dest_portal。

也可使用既有 Dockerfile 啟動 Gunicorn，預設連接埠為 8887。依賴版本沿用原專案；正式伺服器維運前應另行完成依賴更新及相容性驗證。

## GitHub Pages

將 `static/` 內容發布為 Pages 網站即可，不需要 Python 後端。可使用儲存庫內 `docs/` 的相同靜態檔案，在 Settings → Pages 設定 main 分支與 `/docs`。更新介面時執行 `python3 sync_pages.py` 同步。

不要提交個案資料、憑證或環境設定秘密。GitHub Pages 只提供此入口畫面，各外部系統自行管理登入權限。

## 後續規劃

若擴充完整收案系統，需先確認研究計畫欄位、資格規則、帳號角色、同意書版本、資料保存環境與原有系統串接介面，再實作收案表單、家族史編輯、權限與稽核紀錄。本版未自行制定臨床風險判定或研究收案規則。
